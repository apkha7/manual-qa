## About

I am a junior QA tester with hands-on experience in manual testing, API testing, and browser automation. This portfolio documents real testing work done on live web applications including test cases, bug reports, and automation scripts.

All API and automation testing in this portfolio was done on my own initiative, outside of assigned work scope, to build practical skills beyond manual testing.

## Portfolio Structure

### Manual Testing
Testing web and Android mobile applications for three separate LMS (Learning Management System) clients at my previous company. Each platform was an education consultancy that delivered courses, resources, and live classes to students.

**What I tested across all three projects:**
- User authentication — register, login, logout
- Video playback and PDF downloads
- Cart, wishlist, and payment flows
- Zoom live class integration
- Online/offline content availability
- Cross-platform behaviour — web and Android app

**Deliverables produced for each project:**
- Test cases (XLSX and PDF)
- Bug reports (XLSX and PDF)
- Test summary report

| Project | Platform | Type |
|---|---|---|
| 3S Education | Web + Android | LMS / Education Consultancy |
| Columbia Academy | Web + Android | LMS / Education Consultancy |
| Emala Education | Web + Android | LMS / Education Consultancy |
